# Dark Souls Death Screen

Модуль для **Foundry VTT v13 (Build 351)**, воспроизводящий экран смерти и звуковой эффект в стиле Dark Souls при падении здоровья персонажа до нуля.

---

## ✨ Возможности

- **Анимация смерти**: плавное появление надписи/картинки «YOU DIED» при падении здоровья персонажа до 0 или окончательной гибели.
- **Звуковое сопровождение**: атмосферный звук гибели.
- **Условия срабатывания**:
  - *При падении ХП до 0* — экран срабатывает сразу при потере сознания / 0 HP.
  - *При окончательной смерти* — экран появляется после 3 проваленных спасбросков от смерти (в D&D 5e и подобных) либо при получении статуса «Мёртв».
- **Особый экран при ваншоте (One-shot)**:
  - Отдельная анимация и звук при мгновенной смерти от массивного урона или при падении с полного здоровья до 0 за один удар.
- **Гибкая настройка**:
  - Настройка громкости звука, длительности показа, анимации появления/исчезновения и смещения по высоте.
  - Персональный показ: экран отображается владельцам персонажа, а для NPC — мастеру (GM).
  - Поддержка нескольких случайных картинок и выбор звуков через встроенный файловый менеджер Foundry VTT.
- **Поддержка систем**: полностью протестировано и оптимизировано для систем D&D 5e, Naruto 5e (N5eB), World of Darkness, Forbidden Lands и других под Foundry VTT v13.
- **Локализация**: русский и английский интерфейс.

## 📝 История версий

### Версия 1.2.0
- **Выбор условия срабатывания**: добавлена настройка режима смерти — срабатывать либо сразу при падении ХП до 0, либо только при окончательной гибели персонажа (3 провала спасбросков от смерти в D&D 5e / N5eB или статус «Мёртв»).
- **Триггер ваншота (One-shot)**: добавлен отдельный экран при мгновенной гибели (массивный урон по правилам D&D 5e или падение с полного здоровья до 0 за один удар) с возможностью задать свою картинку, свой звук и протестировать их кнопкой в настройках.
- Улучшена надежность отслеживания урона в системах `dnd5e` и `n5eb`.

### Версия 1.1.0
- **Персональный показ**: экран смерти теперь отображается владельцам персонажа (игрокам, управляющим героем), а для существ без игроков-владельцев — только мастеру (GM).
- Оптимизирована сетевая синхронизация через сокеты Foundry VTT.

## 📦 Установка

### Установка по ссылке манифеста (Manifest URL)
1. Откройте Foundry VTT и перейдите во вкладку **Add-on Modules** (Дополнительные модули).
2. Нажмите кнопку **Install Module** (Установить модуль).
3. В поле **Manifest URL** (Ссылка на манифест) вставьте следующую ссылку:
   ```text
   https://github.com/mishalider2004-pixel/ds-death-screen/releases/latest/download/module.json
   ```
4. Нажмите **Install** (Установить).

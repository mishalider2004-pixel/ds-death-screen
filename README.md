# Dark Souls Death Screen

Модуль для **Foundry VTT v13 (Build 351)**, воспроизводящий экран смерти и звуковой эффект в стиле Dark Souls при падении здоровья персонажа до нуля.

---

## ✨ Возможности

- **Анимация смерти**: плавное появление надписи/картинки «YOU DIED» при падении здоровья персонажа до 0.
- **Звуковое сопровождение**: атмосферный звук гибели.
- **Гибкая настройка**:
  - Настройка громкости звука и длительности показа экрана.
  - Возможность показа экрана только владельцу персонажа или всем игрокам за столом.
  - Кастомизация картинки и аудиофайла через настройки модуля в Foundry VTT.
- **Поддержка систем**: полностью протестировано и оптимизировано для систем D&D 5e, World of Darkness, Forbidden Lands и других под Foundry VTT v13.
- **Локализация**: русский и английский интерфейс.

---

## 📦 Установка

### Установка по ссылке манифеста (Manifest URL)
1. Откройте Foundry VTT и перейдите во вкладку **Add-on Modules** (Дополнительные модули).
2. Нажмите кнопку **Install Module** (Установить модуль).
3. В поле **Manifest URL** (Ссылка на манифест) вставьте следующую ссылку:
   ```text
   https://github.com/mishalider2004-pixel/ds-death-screen/releases/latest/download/module.json
   ```
4. Нажмите **Install** (Установить).
